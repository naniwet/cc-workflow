04 · roundtable 详情(手机)

点进一个辩论看的页面。没有 input bar(辩论一次性,问完就跑)。结构 = Question + Round 1 + Round 2 + Synthesis。每个 persona 是独立折叠卡(类似 02 的 turn 折叠)。

关键交互决策

  • 没有 input bar(辩论是一次性,跑完就完;要新讨论开新问题) —— 跟 03 task 详情一致
  • Question 是一等公民(顶部大字),不像 task 的 prompt 是配置项
  • Round → Persona 两层折叠:外层按 Round 分大 section,内层每个 persona 自己一个卡片可独立折叠 / 展开
  • 没有 tool_use / approval / cancel-per-persona:roundtable 是纯文本推理。整个 roundtable 可以 Cancel
  • Synthesis 是高光:purple 边框 + 渐变背景,默认 done 时展开(用户最关心结论)
  • Persona stance chip:`↑ pro` / `↓ con` / `→ flex`,3 类色,在折叠头一眼可见,不必展开看正文
  • 齿轮菜单 3 项:Copy result(synthesis 完成才可点)/ Cancel(active 才可点)/ Delete
