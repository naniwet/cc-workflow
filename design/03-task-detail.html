03 · task 详情(手机)

Tasks tab 点进某个 cron 看到的页面。没有 input bar(无人值守),但齿轮里有 Run now / Pause / Edit。最近一次 run 的 stream 直接在主区域,过去 7 天结果用 sparkline 浓缩。

关键交互决策

  • Cron run = 独立 stream(不像 workspace 多 turn 累积)。详情页只展示最近一次 run 的 stream
  • 不引入 task 级 trust/approval 设置。直接复用 workspace 的 trust=ON。配 cron 前确保 workspace 已信任,否则 cron 跑到工具调用会挂等审批
  • Sparkline (last 7 runs):用 ✓ / ✗ 方块 + 当前 cyan 圈替代完整历史列表。判断"这个 cron 健不健康"够用了,要查具体失败原因走后端 jsonl
  • 没有 input bar(cron 无交互输入)。Run now 在齿轮菜单
  • Stream 渲染规则跟 workspace 一致(thinking / tool_use / tool_result / text + tool_result 长输出折叠 + 浮按钮 ↓ N new) —— 直接复用同一套 render function
  • Cancel放 task header 右侧,不放底部
  • 齿轮菜单聚合所有 task 级配置/操作:Schedule / Prompt / Run now / Pause / Delete
